## Run a website locally

Install [Node.js](https://nodejs.org/) and npm, then choose a project directory and start its Vite development server. For example:

```bash
cd armenia-ssr
npm ci
npm run dev
```

Open the local URL printed in the terminal. To run another site, use its project directory instead. Each project has its own `package.json` and lockfile, so install dependencies from within that directory.

## Available commands

Run these from a project's directory:

| Command | Description |
| --- | --- |
| `npm run dev` | Start the local development server |
| `npm run build` | Build the site for production into `dist/` |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint |
